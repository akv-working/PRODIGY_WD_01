# PRODIGY_WD_01 — Oceanic Marine Conservation Website

A responsive and visually appealing web project built with **HTML, CSS, and JavaScript**.  
This site showcases a marine conservation initiative with sections for mission, projects, initiatives, and a contact form.

## 🌊 Features
- Responsive design with mobile‑friendly navigation
- Sticky navbar that changes style on scroll
- Active section highlighting for smooth navigation
- Interactive contact form with validation and reset
- Dynamic footer year auto‑updated via JavaScript
